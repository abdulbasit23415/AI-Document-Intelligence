# DocuMind Web Client (apps/web)

This is the Next.js 16 App Router frontend for DocuMind.
Features:
- Authentication & Workspace Setup
- Executive Analytics Dashboard
- Comprehensive Document Library with Drag-and-Drop Ingestion
- Document Inspection & PDF.js Preview with Coordinate Bounding Boxes
- 3-Panel Chat Workspace with Verified Clickable Citations
- Document Intelligence Hub (Contract, Invoice, Comparison, Summaries, Export)
- Workspace Team RBAC (Admin, Editor, Viewer)
- System Administrator Settings & Health Diagnostics
